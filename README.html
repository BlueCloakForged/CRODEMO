Static Demo — Cyber Range Orchestrator. No backend, no live data; every screen is a mock.

About this demo

A precomputed, click-through walkthrough of the Cyber Range Orchestrator (CRO) UI — built directly from the application's real screens, navigation, and terminology so it represents what the product actually looks and feels like.

What CRO is

Cyber Range Orchestrator is a platform for designing, deploying, and running cyber ranges: isolated virtual networks used for security training, red/blue exercises, and research. Users build a network topology on a canvas (routers, switches, firewalls, servers, workstations), attach device templates and credentials, run Ansible automation against deployed hosts, and schedule tasks like snapshots or power cycles.

What this demo shows

In scope

  • Real navigation structure and page layout
  • The topology / map editor, with a sample range and a working "add device" panel
  • Projects, Devices, Libraries, Logins, Automation, Tasks, History, Users, Settings
  • Sample, invented data — no real hosts, credentials, or customers

Out of scope

  • No backend — nothing is deployed, saved, or provisioned
  • No authentication — the login screen accepts anything
  • No live automation — Ansible runs and dry-runs are pre-scripted
  • Not every sub-screen of the real app is reproduced

How to use it

Start at the login screen and click through as you would in the real app: log in, create or open a project, drop a device onto the map, open a playbook, schedule a task. Buttons that don't lead anywhere in this demo (Save, Refresh, New User, etc.) show a small toast confirming the click, rather than doing nothing.
